SETUP (one time):
  1. Edit the "Resume" page on jasonhorne.org.
  2. Delete any existing CV Code Block.
  3. Add ONE new Code Block.
  4. Copy everything between the lines below into that Code Block.
  5. Save and publish.

From then on, edit index.html in the resume repo and push; the block
below fetches the latest version every time someone visits.

---------------- COPY FROM HERE ----------------
<div id="cv-embed" style="min-height:300px;">Loading the CV&hellip;</div>
<script>
(function () {
  var SRC = "https://jasonbhorne.github.io/resume/index.html";
  var target = document.getElementById("cv-embed");
  fetch(SRC + "?t=" + Date.now())
    .then(function (r) { if (!r.ok) throw new Error(r.status); return r.text(); })
    .then(function (html) {
      var doc = new DOMParser().parseFromString(html, "text/html");
      var content = doc.getElementById("cv-jbh");
      if (!content) throw new Error("content not found");
      target.innerHTML = content.outerHTML;
    })
    .catch(function () {
      target.innerHTML =
        '<p style="font-family:sans-serif;color:#555;">The CV could not load. ' +
        '<a href="' + SRC + '">View it directly here.</a></p>';
    });
})();
</script>
----------------- TO HERE -----------------------

NOTE: The CV's scoped CSS (<style> under .cv-jbh) lives INSIDE the #cv-jbh div,
so grabbing that one element brings the styling with it. Same approach as the
what-im-reading page.
