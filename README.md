# Resume / CV

The data source for the [Resume](https://jasonhorne.org) page on jasonhorne.org.

`index.html` is the full curriculum vitae for Jason Horne, Ed.D., MBA, SFO,
served via GitHub Pages. The live jasonhorne.org page fetches `index.html` on
load (a single Code Block that pulls the `#cv-jbh` block), so the website
updates itself with no manual editing.

To update: edit `index.html` here, commit, and push. The live page picks up the
change on the next visit.

Live: https://jasonbhorne.github.io/resume/
